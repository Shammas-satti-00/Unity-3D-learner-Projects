# Unity 3D Learner Projects 🎮

Welcome to my **Unity 3D Learner Projects** repository!  
This repository contains multiple Unity projects I’ve created while learning game development.  
Each project explores different aspects of Unity — from first-person shooters and racing games to open-world exploration and flight simulation.

---
---

## ⚙️ Unity Version
All projects were built using **Unity 2022+**.  
Each subfolder contains its own `Assets`, `ProjectSettings`, and `Packages` directories.


Each folder represents an individual Unity project.

---

## 🚀 How to Open
1. Open **Unity Hub**.
2. Click **Add Project from Disk**.
3. Select any of the project folders (e.g., `3D FPS Game`).
4. Let Unity import all assets — first load may take a few minutes.

---

## 🧠 Purpose
This repository is for **learning and experimentation** — exploring C#, gameplay systems, physics, UI design, and Unity’s input systems.

---

## 🔒 Repository Info
- This repository is **private**.
- `.gitignore` is configured for Unity, so no large or unnecessary files (e.g., `Library/`, `Temp/`, `Logs/`) are uploaded.
